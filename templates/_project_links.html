{# Project link pills (Site/GitHub/Docs/Demo/Blog post + stars badge). Split out of macros.html so both the compact project_card and the larger project_section partial can use it without duplicating the block -- Tera rejects a template including itself, same reason _led.html lives on its own (see macros.html's header comment). p: an entry from data/projects.toml (optional repo, site, docs, demo, demo_label, post, stars -- links render only for fields that are present; demo_label replaces the demo link's default domain label, for a demo whose domain says little on its own). #}

{#- Labels name the actual destination (its domain, or "GitHub" for a repo, or "Blog post" for an internal page) instead of a bare category word like "Code" or "Docs", so the link carries real information rather than just acting as a nav label. -#} {% if p.site is defined %} {%- set host = p.site | replace(from="https://", to="") | replace(from="http://", to="") | split(pat="/") | first -%} {{ host }} ↗ {%- endif %} {% if p.repo is defined %}GitHub ↗{% endif %} {% if p.docs is defined %}Docs ↗{% endif %} {% if p.demo is defined %} {%- if p.demo_label is defined -%} {%- set host = p.demo_label -%} {%- else -%} {%- set host = p.demo | replace(from="https://", to="") | replace(from="http://", to="") | split(pat="/") | first -%} {%- endif -%} {{ host }} ↗ {%- endif %} {% if p.post is defined %}Blog post ↗{% endif %} {#- `stars` in data/projects.toml opts a project into the badge and is the fallback count. For a GitHub repo the live count is fetched from the GitHub API at build time (scheduled daily rebuilds in deploy.yml keep it current); if that request fails -- offline, rate-limited, API down -- the build still succeeds and the fallback is shown. GITHUB_TOKEN, when set (CI), lifts the unauthenticated rate limit, which shared runner IPs often hit. -#} {%- if p.stars is defined -%} {%- set stars = p.stars -%} {%- if p.repo is defined and "https://github.com/" in p.repo -%} {%- set gh_slug = p.repo | replace(from="https://github.com/", to="") -%} {%- set gh_api = "https://api.github.com/repos/" ~ gh_slug -%} {%- set gh_token = get_env(name="GITHUB_TOKEN", default="") -%} {%- if gh_token -%} {%- set gh = load_data(url=gh_api, format="json", required=false, headers=["Accept=application/vnd.github+json", "Authorization=Bearer " ~ gh_token]) -%} {%- else -%} {%- set gh = load_data(url=gh_api, format="json", required=false, headers=["Accept=application/vnd.github+json"]) -%} {%- endif -%} {%- if gh and gh.stargazers_count is defined -%} {%- set stars = gh.stargazers_count -%} {%- endif -%} {%- endif -%} {%- endif %} {% if p.stars is defined and p.repo is defined %} ★ {{ stars }} GitHub stars {% elif p.stars is defined %} ★ {{ stars }} GitHub stars {% endif %}
